# Origin Case Study

This template emerged from a six-video portrait series assembled through
After Effects scripts. The workflow evolved from a landscape project into a
file-driven system with semantic slide planning, local audio alignment,
independent text and background decks, internal loop-seam effects, midpoint
reference exports, scripted thumbnails, and publication metadata.

The case study established three forms of project truth:

```text
content truth   = approved transcript and slide content
timing truth    = final audio and timeline JSON
visual truth    = rendered reference frames
```

The public repository contains the reusable architecture, not the original
media, scripts, prompts, production paths, or completed project files.
