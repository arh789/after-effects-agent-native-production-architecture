# Visual System Rules

Universal rules and project styling are separate. The template supplies layout
roles and safe defaults; `design/visual_direction.md` and `style_config.json`
define the current project's appearance.

## Required Hierarchy

- slide reference number, when used;
- kicker or section label;
- primary proposition;
- supporting structural residue;
- emphasis or result;
- readable watermark when it functions as a call to action.

Default portrait output is `1080 x 1920`, `30 fps`, square pixels, and 16-bpc.
All text must be judged at realistic mobile size. Use manual line breaks before
AE wraps or clips a headline.

Do not crowd all text into the upper half. Preserve vertical separation before
the final emphasis. When white support text collides with a red conclusion, move
the supporting text upward before pushing the conclusion toward the unsafe edge.

Emphasis colour is semantic, not decorative. In the optional UV preset, white is
the readable core, violet is emitted light, and red marks contradiction, failure,
pressure, or the decisive payload. Other projects must define their own roles.

Keep text and backgrounds in separate comps. Use scrims only where contrast
requires them and avoid obscuring the image globally without evidence.
