# Contributing

Keep changes small, reproducible, and inspectable.

- Do not commit copyrighted media, model weights, proprietary plugins, fonts,
  audio, AEP files, PSD files, or generated production assets.
- Preserve the separation between editorial content, timing, styling, media, and
  application-generated state.
- Add new project-specific behaviour through configuration before changing the
  shared build architecture.
- Record environment-specific AE effect mappings as optional integrations.
- Validate JSON, Python, PowerShell, and JSX syntax before proposing changes.
- Describe any After Effects or Photoshop application-level test performed.

No contribution licence is implied until the repository owner adds a `LICENSE`.
